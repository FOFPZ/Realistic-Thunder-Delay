Thunder System 1.6.0 — Minecraft Java 1.21.11 / Fabric
Создатель проекта: celestials011

Установка: сделайте копию мира, удалите предыдущий realistic-thunder JAR из папки mods и положите вместо него realistic-thunder-1.6.0.jar. Нужны Fabric Loader 0.18.4+, Fabric API для 1.21.11 и Java 21. Модификация добавляет блок, поэтому сохраняйте резервную копию перед удалением. Для поведения жителей в сетевой игре мод должен быть также установлен на сервере; в одиночном мире работает встроенный сервер.

Изменения 1.6.0:
- В творческом инвентаре добавлена отдельная вкладка «thunder System» с грозовым радаром. Fabric распределяет вкладки по страницам, их номер зависит от других установленных модов.
- Радар: масштаб колесом мыши, указатели сторон света, координаты наведённой клетки, а при наведении на отметку — координаты удара и время с момента появления. Жёлтый — удар по земле, розовый — декоративная молния в небе, бирюзовый — игрок, белый — радар. Только данные загруженных чанков и молнии, полученные клиентом, без прогнозов или настоящих локальных грозовых фронтов. В ванильной игре погода общая для измерения.
- Небесная молния реже: каждая попытка через 45–90 секунд с шансом 75%. Звук тише и короче; это обработанная запись реального грома, а не ИИ. Небесные молнии декоративные и клиентские.
- Добавлены отдельные короткие записи дождевых капель под блоками; потолок проверяется на высоте до 32 блоков. Звук относится к категории «Погода». Воспроизведение рассчитано на дождливый биом. Это попытка исправить пропажу звука; реальную причину именно в вашей сборке без лога определить нельзя.
- Лужи визуально неровные с бликами. Это временные клиентские эффекты, не изменяют блоки и не имеют настоящих отражений.
- Новая процедурная бесшовная текстура облаков с мягкими переходами и затемнением при дожде. Minecraft продолжает отрисовывать облака своей стандартной геометрией: фотореалистичная объёмная система НЕ реализована. Некоторые ресурс-паки и шейдеры могут заменять облака мода.

Рецепт радара: компас в верхнем центре; железный слиток, редстоун, железный слиток в средней строке; громоотвод в нижнем центре. Или /give @s realistic_thunder:storm_radar. Поставьте блок и нажмите ПКМ.
